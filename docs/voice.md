# قلم | QALAM — المساعد الصوتي

المرحلة ٦.

---

## المعمارية

```
الميكروفون → MediaRecorder → دالة قلم → Whisper → نص
                                                   ↓
                                        تصنيف النيّة
                                       ↙      ↓      ↘
                                  حسّاسة   تنقّل    سؤال
                                     ↓       ↓        ↓
                              رد + فتح   فتح مع    وكيل قلم
                               الشاشة    ما نُطق
                                     ↘      ↓      ↙
                                       نص + نطق
```

**المساعد الصوتي يركب فوق وكيل المرحلة ٥.** كل ضمانات الوكيل — الأدوات للقراءة
فقط، RLS، حدود الحلقة، الاستشهاد — هي ضمانات المساعد الصوتي نفسها. لم نبنِ
مسارًا موازيًا.

---

## ⚠️ الخصوصية — قرارات صريحة

### الصوت الخام لا يُخزَّن. في أي موضع.

لا Storage · لا قاعدة بيانات · لا ملف مؤقت · لا `localStorage` ولا `IndexedDB`.
التسجيل يعيش في الذاكرة، يُحوَّل، ويُهمَل. اختبار ساكن يفشل إن ظهر أي من ذلك في
الكود.

### لماذا Whisper لا واجهة المتصفح؟

واجهة `SpeechRecognition` مجانية — وترسل الصوت إلى خوادم **مزوّد المتصفح**.
طرفٌ ثالث جديد لا نتحكم به ولم يوافق عليه المستخدم.

OpenAI يرى نصوص المراسلات أصلًا. إرسال الصوت إليه **لا يفتح حدَّ ثقة جديدًا**.

المفاضلة ليست «مجاني مقابل مدفوع» بل **حدَّا ثقة مقابل حدٍّ واحد**.

### ولماذا النطق في المتصفح؟

`speechSynthesis` يركّب الصوت **على الجهاز**. نص الرد لا يغادر المتصفح إطلاقًا.
مزوّد سحابي أفضل صوتًا، لكنه يعني إرسال نص المراسلة إلى الشبكة مرة أخرى لأجل
الجمال — مقايضة لا تستحق في نظام مراسلات.

### ما يُسجَّل

`voice.transcribed`: المدة، حجم الصوت بالبايت، وهل كان الناتج فارغًا.
**لا النص المنطوق ولا أي جزء منه.**

وجسم خطأ المزوّد لا يُقرأ — قد يحمل صدى ما نُطق.

## صلاحية الميكروفون

```
Permissions-Policy: microphone=(self)
```

`(self)` لا `(*)`: أصل الموقع وحده. لا إطار ولا نطاق فرعي ولا طرف ثالث.

**الصلاحية تُطلب عند ضغط الزر لا عند تحميل الصفحة.** طلبها مبكرًا يُخيف المستخدم
ويُعلّم المتصفح رفضًا دائمًا يصعب التراجع عنه. فحص الدعم
(`typeof …getUserMedia === 'function'`) لا يطلب شيئًا؛ الاستدعاء وحده يفتح النافذة.

**الميكروفون يُحرَّر في كل مسار** — نجاح وإلغاء ومغادرة الصفحة — فينطفئ مؤشر
التسجيل في المتصفح فورًا. لا تسجيل يستمر خلف المستخدم.

**الحالات الست** معروضة صراحةً: سكون · استماع (بنبض أحمر) · معالجة · نطق · خطأ ·
رفض صلاحية. لا تسجيل خفي.

## ⚠️ الأوامر الحساسة

```
«اعتمد الكتاب»
  ↓
لا يصل الوكيل أصلًا
  ↓
«الاعتماد قرارٌ لا أتخذه نيابةً عنك. سأفتح لك شاشة الاعتماد.»
  ↓
navigate('/my-work')   ← تنقّل لا فعل
```

| الأمر | الرد | المسار |
|---|---|---|
| اعتمد · صدّق | لا أتخذه نيابةً عنك | `/my-work` |
| وقّع | التوقيع باسمك لا أقوم به | `/my-work` |
| أصدر | يحتاج تأكيدك | `/my-work` |
| ارفض · أعد | يحتاج سببًا مكتوبًا | `/my-work` |
| **احذف** | لا يُلغى — افتحها بنفسك | **لا مسار** |
| **غيّر التصنيف** | لا أقوم به | **لا مسار** |
| امنح صلاحية | لا أقوم به | `/organization/users` |

**الحذف وتغيير التصنيف لا يفتحان شاشة تنفيذ.** فتح شاشة الحذف بالصوت خطوة واحدة
من الكارثة.

**الأمر الحساس يتقدّم على التنقّل:** «اعتمد الكتاب واكتب لي مراسلة» تُعامل طلبَ
اعتماد — لا تُبتلع الكلمة الخطرة داخل نيّة أخرى.

### هذا ليس الحاجز الأمني

الحاجز بنيوي: **وكيل قلم بلا أدوات كتابة إطلاقًا**. لو فشل كل تصنيف النيّات في
التعرّف، لا يقع فعل — لأنه لا يوجد فعل يقع. ملف النيّات تجربةٌ صادقة لا حماية:
الفرق بين مساعد يفهم وآخر يتهرّب.

واختبار يفشل إن ظهر `supabase` أو `rpc(` أو `fetch(` في ملف النيّات.

## التنقّل يحمل ما نُطق

```
«جهّز لي كتاب لوزارة المالية نطلب البيانات قبل الخميس»
  ↓
navigate('/write', { state: { idea: 'جهّز لي كتاب…' } })
```

بدون تمرير النص تُفتح شاشة فارغة، فيضطر المستخدم لإعادة كتابة ما نطقه للتو.
`write` تمرّر `idea` و`reply` تمرّر `incomingText`.

**لماذا التنقّل لا التوليد في الرد الصوتي؟** صفحة الكتابة تُنتج ثلاث صيغ
مُتحقَّقًا منها بـZod مع مراجعة قبل الإرسال — أفضل من نص حر يقوله المساعد.

## العربية

`language: 'ar'` مضبوطة صراحةً في Whisper — الاكتشاف التلقائي يخلط العربية
بالفارسية والأردية.

أنماط النيّات تغطي الفصحى واللهجة الخليجية: «اعتمد» و«صدّق» و«سوّي» و«طلّع»
و«جهّز» و«شو المطلوب» و«وش علي».

### ⚠️ فخّ تقني وقعنا فيه

`\b` في JavaScript مُعرَّف على `[A-Za-z0-9_]` وحدها. الحروف العربية ليست منها،
فـ`/\baعتمد\b/` **لا تطابق** «اعتمد الكتاب» إطلاقًا.

البديل حدود واعية بـUnicode: `(?<!\p{L})…(?!\p{L})` مع الراية `u`.

كل أنماط النيّات مبنية بدالتَي `word()` و`phrase()` اللتين تطبّقان ذلك.

## تبديل المزوّد

```
src/services/voice/
  types.ts       عقد SttProvider و TtsProvider
  whisperStt.ts  عبر خادم قلم        (الافتراضي)
  browserTts.ts  المتصفح، على الجهاز  (الافتراضي)
  registry.ts    التسجيل والتفعيل
```

مزوّد جديد = ملف ينفّذ الواجهة + سطر في السجل. لا تعديل في أي مكوّن.

كل مزوّد يُعلن `onDevice` — والواجهة تعرض للمستخدم أين يُعالَج صوته.
